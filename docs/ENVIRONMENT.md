# ENVIRONMENT — software factory

Environment variables and config keys only. Placeholders only — never real secret values.
The user populates real secrets.

| Variable | Where used | Required | Default | Notes |
|---|---|---|---|---|
| `BASH_ENV` | the whole dev container | no | `/home/node/.shell-redact.sh` | Points bash at the startup file that scrubs credentials from command output and refuses any `bash -c` command that names a protected file. Set by `devcontainer.json` → `remoteEnv`. If the file is missing bash ignores it. |
| `CLAUDE_PROJECT_DIR` | guard hook | no | set by Claude Code | The launch directory; the hook walks up from it to the nearest `guard.py`. Not set by hand. |
| `REMOTE_CONTAINERS_IPC` | VS Code Dev Containers | no | set by VS Code | The socket the VS Code credential helper talks to. Not set by hand. |
| `ANTHROPIC_API_KEY` | Claude Code in the dev container | no | — | Optional; value lives in the host environment and is passed through `remoteEnv`. Leave unset to sign in with `claude` instead. |
| `CARGO_BUILD_JOBS` | Rust builds | no | `2` | Passed through `remoteEnv` from `FACTORY_CARGO_JOBS`. |

## Config keys

| Key | Where | Notes |
|---|---|---|
| `/home/node/.shell-redact.sh` | the whole dev container | The startup file. It scrubs credentials from command output and refuses `bash -c` commands that name a protected file. Installed by `postCreateCommand` from `.devcontainer/shell-redact.sh`. |
| `/home/node/.git-credentials` | the whole dev container | The git credential store, mode `600`. Never commit it and never read it into a transcript. |
| `/home/node/.gitconfig` | the whole dev container | Holds `credential.helper`, `user.*` and `safe.directory`. It must not hold a `url.*.insteadOf` rewrite that embeds a credential. |
| `mode` | control repo common Git directory `claude-workspace.json` | Project-local `required` (default), `optional` or `adaptive`; the guard hook reads it on every tool call, so no restart is needed. |
| `.claude/settings.json` | every checkout Claude Code is launched in | Generated by `guard.py check-policy --write`: static deny/allow rules plus the `guard.py hook` PreToolUse hook. Claude Code does not read it from parent folders, so worktree creation and restore write one per checkout. Personal overrides go in ignored `.claude/settings.local.json`. |
| `.claude/local/qa-auth.json`, `.claude/local/qa-storage-state.json` | standalone QA capture | Human prepares ignored, private state for this project. See [setup and renewal](../.claude/skills/qa-review/SKILL.md#authentication); no login environment variables required. |

## Rules

- Builders may create or update `.env.example` files.
- Builders do not edit real `.env` files; use `.env.example` placeholders only.
- Real secrets are never generated, requested, stored, or committed by an agent.
- Stack, commands, and ports belong in `docs/STACK.md`, not here.
- A credential never goes in a URL, a command line, a config value that a command prints, or a
  document. The redaction file scrubs it from command output; that is the backstop, not the plan.
